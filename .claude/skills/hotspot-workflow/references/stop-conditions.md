# stop conditions

## 何时读取
当需要判断当前 workflow 是否应继续执行、暂停，或向用户说明阻塞原因时读取本文件。

## 共用停止条件
仅在以下情况停止并向用户说明：

- 需求本身不明确，无法合理实现
- 现有改动与当前任务直接冲突，无法在不影响用户现有工作的前提下继续
- 仓库内规则彼此冲突，且无法按根 `CLAUDE.md` 的优先级直接裁决
- 测试或 Docker 隔离验证持续失败且无法自主修复
- 线性合并遇到需要用户裁决的冲突
- 动作将影响远程仓库、外部服务或共享资源，例如 `git push`、`gh`、线上环境操作
- cleanup 候选项的用途、归属或保留价值无法安全判断
- 用户尚未明确授权进入主线同步、删除临时工作区 / 分支或其他高副作用收尾动作
