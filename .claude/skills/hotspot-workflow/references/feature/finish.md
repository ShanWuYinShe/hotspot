# feature / finish

## 何时读取
在实现与验证完成、准备结束当前 feature 工作阶段时读取本文件。

## 执行要求
1. 先确认当前结果满足目标状态：`开发完成` 或 `准备合并`。
2. 若改动涉及数据库写入、迁移、跨服务联调或真实环境链路，先完成 `integration.md` 中要求的 Docker 隔离验证。
3. 查看当前 worktree 分支上的提交，确保变更边界清晰；若需要提交，最终 commit message 必须符合 `<type>(<scope>): <subject>`。
4. 整理验证结论、剩余风险与后续建议，向用户明确说明当前已达到的状态。
5. 除非用户明确要求进入主线同步、合并或清理阶段，否则本文件到此结束，不默认切回主目录，也不默认删除 worktree / 分支。

## 完成标准
- 实现与必要测试已完成。
- 已达到目标验证级别：仅本地校验通过，或在需要时 Docker 隔离验证也已通过。
- 当前 worktree 内结果可交付、可继续评审、或可进入后续合并阶段。
- 若尚未进入主线同步 / cleanup，需在汇报中明确说明后续仍待用户决定。
