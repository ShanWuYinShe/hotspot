# feature / implementation

## 何时读取
在进入具体实现前读取本文件。

## 执行要求
1. 阅读根目录与相关子项目 `CLAUDE.md`，确认分层约束、测试边界和子项目规则。
2. 若涉及 API、字段、错误码、分页、幂等等契约，核对 `spec/`。
3. 根据根 `CLAUDE.md` 判断任务级别：`L0/L1` 直接实现，`L2` 先做简短计划，`L3` 先设计再计划。
4. 使用 `git worktree` 创建隔离工作区；默认目录为 `.worktrees/`。所有代码修改、测试与提交都在 worktree 内进行。
5. 若主目录存在与当前任务无关的未提交改动，不要回退或覆盖它们；仅在这些改动直接阻塞当前任务时再说明情况。
6. 在 worktree 中完成实现，并补齐必要测试。
7. 后续所有校验命令（编译、lint、测试）都必须在 worktree 目录内执行，不得切回宿主主目录。
8. 除非遇到真正阻塞的问题，否则不要在中途停下来征求确认。
