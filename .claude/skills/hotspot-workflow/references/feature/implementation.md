# feature / implementation

## 何时读取
在进入具体实现前读取本文件。

## 执行要求
1. 阅读根目录与相关子项目 `CLAUDE.md`，确认分层约束、测试边界和子项目规则。
2. 若涉及 API、字段、错误码、分页、幂等等契约，核对 `spec/`。
3. 检查主目录是否存在与当前任务无关的未提交改动；若存在，停止并说明。
4. 使用 `git worktree` 创建隔离工作区；所有代码修改、测试与提交都在 worktree 内进行。
5. 在 worktree 中完成实现，并补齐必要测试。
6. 除非遇到真正阻塞的问题，否则不要在中途停下来征求确认。
