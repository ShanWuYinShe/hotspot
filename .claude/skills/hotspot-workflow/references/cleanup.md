# cleanup

## 何时读取
在进入 worktree / 分支盘点与清理阶段时读取本文件。

## 执行要求
1. 列出所有 `git worktree`。
2. 确认主目录状态：位于 `main` 分支且无与清理动作无关的未提交改动。
3. 识别已合并到 `main` 的临时分支，并检查它们是否仍关联 worktree。
4. 对每个候选项核实：
   - worktree 内没有未提交改动
   - 分支不存在未合并的重要提交
   - 名称与用途符合临时工作区特征
5. 对可明确判定为安全的项，直接执行清理：
   - 删除 worktree：`git worktree remove <路径>`
   - 删除分支：`git branch -D <分支名>`
6. 对状态不明、存在未提交改动、或用途看起来不是临时分支的项，不要删除；把原因写清楚后汇报给用户。

## 安全边界
- 主目录 worktree 和当前正在使用的 worktree 不在清理范围。
- 只有在“已合并且干净”或“明确废弃且无保留价值”时才删除。
- 若发现未合并提交、未提交文件或用途不明，停止删除该项并解释原因。
