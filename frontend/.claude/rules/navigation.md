# 导航与页面框架

## 设备导航模型（四档基线）

断点：桌面 `≥1280`；平板 `min(w,h)≥600 且 <1280`；其余移动。`isWide = 宽度≥960`。

| 档位   | 导航 chrome                                            | 内容布局                             |
| ------ | ------------------------------------------------------ | ------------------------------------ |
| 桌面   | 顶栏(52px) + 常驻侧边栏(192px)                         | `desktop-main-card` 内经 shell 收束  |
| 宽平板 | 浮动玻璃药丸底栏 `TabletBottomNav`（4 tab + 中央 FAB） | **复用桌面双栏**；chat 走 split-pane |
| 窄平板 | 同上浮动玻璃底栏                                       | **单列** shell + `page-pad`          |
| 移动   | 通栏底栏 `MobileBottomNav`（4 tab + 中央 FAB）         | 单列；左右各约 16px 兜底留白         |

- 底栏只放 4 个高频顶层目的地 + 中央发布 FAB。其余项经「我的」或首页「查看全部」下钻进入。
- `/users/nearby`、`/groups/nearby` 属于 `SUB_PAGE_EXACT`（隐藏底栏 + 带返回）。
- 首页附近人/群组区块标题与入口常驻，不随数据条件隐藏。

## 返回按钮

- **顶层目的地**（侧边栏可直达）：桌面不显示返回；移动/平板保留。
- **钻取页/详情页**：三档设备都保留返回。

## 不重复入口

- 位置与半径调整唯一入口：侧边栏底部 `AnchorEntry`（桌面）/ 头部 pill（移动·平板）。
- 发布、搜索、通知、设置等已在顶栏/侧边栏存在的全局动作，不在页面内重复放置。

## 路由收敛

同一类内容只保留一个顶层路由；近重复用页内 `filter-chip` 分页。已废弃路由保留 `+page.ts` 重定向。

- **关系**：`/relations` 是唯一入口，三者为页内 tabs。列表用 `UserCard variant="square"` + `usePagination`。
- **首页**：`/dashboard` 重定向到 `/`。
- `formatHandle({ nickname, user_id })` 是 @handle 的唯一共享 helper。

## 一致性审查清单（硬约束）

### 图标

- 同一侧边栏内同列图标必须各不相同。
- 同名近义入口须用不同图标，图标 + 语义双重消歧。
- 设置项图标单色 `--text-secondary`，按语义选用专图标：`MonitorSmartphone`（会话管理）、`EyeOff`（隐私）、`Flag`（举报）。
- chat 空态用 `MessageCircle`，与「消息」导航图标统一。

### 一个动作一个入口

- 一页同一动作只保留一个入口（如 `我的群组` 单一 `refreshAll()`）。
- 桌面通知统一由侧边栏「通知」单一入口 + 单一角标。
- 顶栏只保留不与侧边栏导航重复的工具动作（搜索 / 主题 / 配色 / 发布 / 设置 / 头像）。

### 派生展示字段

- `@handle`、距离、相对时间、计数缩写等展示值必须走唯一共享 helper，禁止各页内联。

### 版式密度

- 宽档概览卡用 `StatSegments` 横向填充，不得内容堆左留白右。
- 等高卡片用 CSS Grid，不等高用 `columns-*` 瀑布流。
- `EmptyState` 整页空态传 `fill`（垂直居中），下方有并列内容不传。
- 顶层 feed 页右栏策略：有真实补充模块才挂右栏；筛选结果列表型铺满全宽。

### 标题与交互

- 门面页/管理·配置页可带副标题，纯内容列表页一律不带。
- 搜索全站即时（输入即搜，防抖）。
- profile 左栏个人中心快捷入口桌面隐藏（侧边栏已直达）。
