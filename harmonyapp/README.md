# HotSpot HarmonyOS App

基于 HarmonyOS ArkTS 的鸿蒙客户端，是 HotSpot 的移动端。

## 功能

- 认证与多账户切换
- 附近的人、群组、生活瞬间
- 私聊与群聊
- 地图浏览与位置选择
- 发现与搜索
- 通知与公告
- 个人中心

## 技术栈

- **框架**：HarmonyOS ArkTS
- **构建工具**：hvigor
- **网络**：@ohos.net.http
- **持久化**：@ohos.data.preferences
- **UI**：ArkUI
