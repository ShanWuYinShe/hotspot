# HotSpot Frontend

基于 SvelteKit + Svelte 5 的 Web 前端应用。

## 技术栈

- **框架**：SvelteKit + Svelte 5
- **样式**：Tailwind CSS
- **UI 组件**：bits-ui + lucide-svelte
- **通知**：svelte-sonner

## 验证命令

```bash
pnpm check
pnpm build
```
