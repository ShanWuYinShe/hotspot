## 关于自动创建 Figma 命名版本的说明

当前云自动化通道**无法**程序化创建 Figma 命名版本：

- 插件 API `figma.saveVersionHistoryAsync` 仅限 Enterprise 方案，当前运行时返回
  "not a supported API"
- Figma REST API 无公开的「创建版本」端点（versions 仅 GET）

因此：需要命名版本时，请在 Figma 中 **File → Save version** 手动录入，
描述可直接复制本文件对应条目。本文件由自动化流程持续追加。
