## 关于自动创建 Figma 命名版本的说明

- **云端 MCP 通道**：`figma.saveVersionHistoryAsync` 在云端沙盒未开放，REST API `/v1/files/:key/versions` 仅只读。
- **现行程序化通道（推荐）**：通过 **Figma Local Bridge**（桌面插件 + 本地 CLI），直接在 Figma 桌面运行时调用 `figma.saveVersionHistoryAsync` 原生接口：
  ```bash
  node scripts/design-kit/figma-bridge.mjs save-version -t "版本标题" -d "更新描述"
  ```
  （服务未启动时 CLI 会自动在后台静默拉起，秒级完成打点并同步到 Figma 版本历史）。
- **备用方式**：在 Figma 桌面端中快捷键 `Cmd+/` 输入 `save to version history` 手动录入，描述可直接复制本文件对应条目。
