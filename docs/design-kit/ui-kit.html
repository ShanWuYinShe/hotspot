导入 Figma / Stitch 与迭代流程

Figma：① 新建文件；② 安装 Tokens Studio 插件并导入 tokens/global.json 与 tokens/themes/*.json（一个主题一个 set）；③ 把 pages/*.png|jpg 拖入画布作为参考层（或逐页 Place image）；④ 用 Components 区截图/说明建立 Figma 组件库（按钮/输入/列表/Tab/弹层）。

Stitch：在 Stitch 新建项目，上传 pages/ 中的截图作为参考图，并粘贴 README 的「设计约束」段落作为生成提示；后续迭代以本页 token 与截图为准，Stitch 产出需回填到代码 token 后重新生成本页。

迭代：改代码 token（frontend themes / semantic / shared 或 harmonyapp DesignConstants）→ 重新运行 node scripts/design-kit/build-tokens.mjs 与 node scripts/design-kit/build-ui-kit.mjs → 重新截图 → 提交。校验：bun run check:theme、python3 harmonyapp/scripts/check_status_parity.py。
