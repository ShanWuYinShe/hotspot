# Android 端 UI 走查基线

本文记录 Android 客户端**当前版本**的端上 UI 走查口径与已确认结论。已确认达标的页面不重复走查；新增页面按本文方法复测对应项。

## 走查环境

- 设备：`HotSpotPhone` AVD（1080×2400，API 36），`adb reverse tcp:8888 tcp:8888` 联调 dev 后端。
- 构建：`./gradlew --no-daemon assembleDebug -PHOTSPOT_DEBUG_BASE_URL=http://127.0.0.1:8888`。
- 账号：`admin@hotspot.local`（平台管理员，可进入管理后台）。
- 主题入口：我的 → 设置 → 应用主题（星际/清野/水墨）+ 外观模式（浅色/深色）。
- 判定以**截图**为准；`uiautomator dump` 只用于定位，不单独作为页面正常的证据。

## 主题矩阵（管理后台）

覆盖 3 主题 × 明暗共 6 套，逐套进入「设置 → 管理后台」，检查管理首页与全部管理模块：举报审核、用户管理、群组管理、系统公告、统计分析、权限与角色、标签管理（重点看搜索框、筛选 tab、统计图表、列表行与操作按钮）。

| 主题 | 外观 | 管理首页 | 举报审核 | 结论 |
|---|---|---|---|---|
| 星际（vibrant） | 浅色 | 浅蓝画布 + 白色卡片，标题/说明对比清晰 | 搜索框、待处理计数、通过/驳回按钮对比正常 | 通过 |
| 星际（vibrant） | 深色 | 深蓝画布 + 深色卡片，文字/分隔线可见 | 搜索框与按钮（蓝底）在深色下可辨 | 通过 |
| 清野（forest） | 浅色 | 浅绿画布 + 白色卡片，层级正常 | 绿色主按钮与浅底对比正常 | 通过 |
| 清野（forest） | 深色 | 深绿画布 + 深灰卡片，文字对比正常 | 搜索框、按钮与背景分层清楚 | 通过 |
| 水墨（inkwash） | 浅色 | 米白画布 + 白色卡片，弱对比但可读 | 深色文字/按钮在米白底可读 | 通过 |
| 水墨（inkwash） | 深色 | 深灰画布 + 深色卡片，文字/图标可见 | 搜索框、按钮、计数文案可辨 | 通过 |

其余管理模块抽查（6 套主题均通过）：
- 用户管理/群组管理：搜索框、筛选 tab、行标题/副标题、封禁/解散按钮对比正常；
- 系统公告：级别 tab、搜索框、编辑/删除按钮在浅色/深色下均可辨；
- 统计分析：存量卡、近 7 日柱状图（主题强调色）、热门地点/区域列表文字与分隔线正常；
- 权限与角色：管理员/角色/权限 tab、授权/刷新按钮、角色摘要与「没有更多了」可读；
- 标签管理：搜索框、使用次数/创建时间副标题、屏蔽按钮对比正常。

共同检查项（6 套均通过）：

- 系统栏图标颜色随主题切换（浅色主题深色图标、深色主题浅色图标）；
- 页面背景/卡片/分隔线/次级文字层级可辨，无「白字白底」或「黑字黑底」；
- 搜索框 placeholder、空态/错误态、加载态沿用语义 token，无硬编码颜色；
- 管理后台入口卡片、行标题/副标题、列表行间距一致，无截断或重叠。

## 交互态抽查

在 6 套主题下抽查覆盖层与全屏交互态：

| 交互态 | 检查内容 | 结论 |
|---|---|---|
| 消息长按操作面板 | 遮罩、面板背景、复制/举报项、分隔线、圆角 | 6 套均通过 |
| 聊天图片全屏查看器 | 黑色沉浸背景、关闭按钮、图片居中 | 6 套一致（有意固定深色） |

长按操作面板的背景/文字/分隔线随主题变化，遮罩不会让底层内容失真；图片查看器固定黑底，属于设计预期，不随主题切换。

## 搜索相关页面走查

长列表搜索（用户/群组/标签、举报审核、系统公告、群组详情成员、统计区域下钻、通知中心、我的举报、屏蔽名单）按以下项检查：

- 搜索框在浅色/深色下均可见，placeholder 与输入文字对比正常；
- 输入关键词后显示「已加载/匹配」计数（或「共 N 条 · 匹配 M 条」），清空后恢复全量；
- 无匹配时显示独立空态，不回退为「暂无数据」；
- 搜索期间列表滚动位置与底部「加载更多」/「没有更多了」状态一致。

## 复现方式

```bash
# 启动模拟器并安装 debug 包（需本机 Android SDK）
adb reverse tcp:8888 tcp:8888
adb install -r androidapp/app/build/outputs/apk/debug/app-debug.apk

# 登录后：我的 → 设置 → 应用主题/外观模式，逐套切换；
# 再进入 设置 → 管理后台，截图管理首页与举报审核列表。
```

截图仅作为 PR 附件，不入库。
