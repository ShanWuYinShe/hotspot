# 端上走查坐标与可达页面基线（hotspot 鸿蒙模拟器）

本文件是 skill `hotspot-harmony-device-verify` 的实测基线：坐标**随每次构建会变**，一律先用 `uitest dumpLayout` 取 bounds 再点；此处数值用于快速比对与回归。分辨率 1256×2760、Pura 90 Pro 实例、密度 ≈3.917。

## 首启定位权限框

文本「允许「GeoTalk」访问你的位置？」，「仅使用期间允许」中心 ≈ `(628,1964)`（bounds `[432,1931][824,1997]`）。不处理会挡住所有页面断言（dump 只有弹窗节点）。

## 免登录 / 需登录页面清单

- **免登录可走查**：首页、附近枢纽、附近的人/群组/瞬间、瞬间详情、搜索、消息（游客态）、我的（游客态）、登录页。
- **需登录**：通知、设置、我的瞬间/群组/关系/举报、编辑资料、聊天、管理后台。

## 其他基线

- 底栏中心 `y=2599`；写成 `2620` 会落进系统手势区（会被切回桌面）。
- 「快速体验」→「开始体验」按钮坐标每次以 dump 定位（弹层位置稳定在 y≈2358，但勿硬编码——曾在 2255 点空）。
- 设置浏览锚点：长按放置 `uitest uiInput longClick <x> <y>`；模拟器系统地理编码无数据（地点搜索恒「未找到该地点」、锚点名恒「未知位置」），真机不受影响。
- dump bounds 换算 vp 用 3.917（1256px / ≈320vp），不要用 3.25。
